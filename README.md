# 游戏开发资料库

这里收集可复用的游戏开发经验、技术知识和 Codex Skills。

| 目录 | 存放内容 |
| --- | --- |
| [游戏开发经验包](./experience-packs/) | 来自实际项目的案例、踩坑记录和解决方案。每个经验包可以包含适用场景、排查过程、验证结果，以及相关脚本或示例。 |
| [游戏开发知识库](./knowledge-base/) | 可按主题查阅的技术资料，例如引擎用法、动画、渲染、性能优化和发布流程。 |
| [Codex Skills](./skills/) | 可复用的 Codex 工作流程。每个 Skill 单独建一个目录，以 `SKILL.md` 为入口，配套脚本和参考资料放在同一目录下。 |
| [项目模板](./projects/) | 可直接打开的工程模板，如 [MiniGameTemplate](./projects/MiniGameTemplate/)（团结引擎 + 微信/抖音双平台小游戏模板）。 |
- [知识库任务索引](./knowledge-base/README.md) · 按「要做什么」查条目：找现成实现、选外部库、UI 拼接
- [UI Workflow](./ui-workflow/README.md) · PhotoCraft 拆图、结构化交付、Unity 和 Cocos Prefab 导入
