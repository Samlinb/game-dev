### 搜索策略

- GitHub：`gh api search/code?q=repo:...+关键词` 有效；被封仓库返回 403。
- 项目内搜索：用 Grep/Glob 直接搜（不依赖子智能体扇出）。
- Unity 手册深层页：先 WebFetch 目录/index 页取所有子页 href，再抓具体页；直接猜 slug 会 404。
- 微信/抖音文档：IAB 浏览器 → goto → waitForLoadState → wait 3s → evaluate body.innerText；抖音首抓可能只回导航，再 wait 3s 重读。
- 微信适配文档子页路径：`/minigame/dev/guide/game-engine/unity-webgl-transform/Design/<Name>.html`。
