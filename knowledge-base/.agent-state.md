### 搜索策略

- GitHub：`gh api search/code?q=repo:...+关键词` 有效；被封仓库返回 403。
- 项目内搜索：用 Grep/Glob 直接搜（不依赖子智能体扇出）。
- Unity 手册深层页：先 WebFetch 目录/index 页取所有子页 href，再抓具体页；直接猜 slug 会 404。
- 微信/抖音文档：IAB 浏览器 → goto → waitForLoadState → wait 3s → evaluate body.innerText；抖音首抓可能只回导航，再 wait 3s 重读。
- 微信适配文档子页路径：`/minigame/dev/guide/game-engine/unity-webgl-transform/Design/<Name>.html`。
- Unity Manual 深层页策略：**先抓目录页**（如 `webgl-develop.html`）拿到所有子页 href，再逐页 WebFetch；直接猜 slug（如 `webgl-debug.html`）可能命中失败；302 跟随 `docs.unity3d.com/Manual/*.html` → `docs.unity.com/en-us/engine/<ver>/manual/...` 是稳定的。
- Unity Scripting API 页面（`docs.unity3d.com/ScriptReference/*.html`）WebFetch 直接失败时，用 WebSearch 摘要里的参数信息 + Manual 正文替代；PlayerPrefs 在 WebGL 的 IndexedDB + 1MB 限制可在 Manual webgl-memory.html 旁读到。
- **平台适用性结论的三层证据链**（round 21 KB-025 验证高效）：① 版本匹配的包文档（如 VFX Graph @14.0 System-Requirements 给「不支持 OpenGL ES」原文）× ② 上游 current 手册（WebGL2/WebGPU 对比表给 compute 支持状态）× ③ 团结平台页（WebGLPlatform 给平台级确认+性能特征）。三层一致才写「官方规定」；只有一层时标适用版本边界。
- Unity current 手册（6000.6）查新主题：从 `docs.unity3d.com/Manual/<旧slug>.html` 302 进入，目录页逐层取子页 href；**不要从旧 slug 猜新路径**（新路径是 /manual/<章节>/<主题> 语义化结构，与旧 slug 无对应规律）。
- 微信 Design/ 导航壳页面也有价值：导航树可确认**页面存在与标题**（如 ParticleBudget），据此登记待核对项而非臆测内容。
- D 方向搜索场景甄别（round 47）：「unity webgl build」高星结果是网页嵌入（react-unity-webgl 1888★）非小游戏容器，不适用本项目；微信小游戏 CI 官方工具主导无成熟社区方案；低星（0★）候选 gh api 核 README+license+pushed 定参考价值（UnityMinigameSDKTool 无 LICENSE 仅思路参考），不只看星数。
