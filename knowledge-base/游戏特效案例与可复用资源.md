# 游戏特效案例与可复用资源

适用：团结引擎 / Unity 2022.3 WebGL 微信+抖音小游戏（Particle System 路线，VFX Graph 不可用见 KB-025）。
触发：制作命中反馈/技能范围提示/状态持续效果/奖励演出，找案例、教程、可复用工具与素材。
核对日期：2026-11-14（GitHub 仓库 README + license 经 gh api 核实）。
前置：技术实现（选型/粒子/拖尾/Shader/Bloom/预算）主存 [Unity 小游戏特效实现与性能](./Unity小游戏特效实现与性能.md)（KB-025）；本条目讲「什么场景用什么组件 + 有哪些可复用资源」。

## 结论速览

1. **四类场景都用 Particle System 组件拼**（VFX Graph 不可用）：命中=闪光+粒子+拖尾分层，范围=贴地 mesh/Shader，状态=循环低粒子，奖励=爆发粒子+序列。组件技术主存 KB-025。
2. **可复用工具优先于素材**：GitHub 专用命中特效素材仓库稀缺（多 Asset Store 付费），但有两个 MIT 许可工作流工具直接可用——ParticleEffectProfiler（性能分析 524★）+ UnityParticleSystemPreview（预览 317★）。
3. **复用资产必核许可证**：MIT 可复用；keijiro/ShurikenPlus 无 LICENSE 仅思路参考；Asset Store 素材按各自 EULA。

## 1. 四类制作场景 → 技术方案（设计映射，组件主存 KB-025）

| 场景 | 表现要点 | 推荐组件组合 | KB-025 章节 |
|------|----------|--------------|-------------|
| 命中反馈 | 瞬时、强反馈、短时长 | 闪光（Shader 发光/billboard 片）+ 爆发粒子（少量高速）+ 可选拖尾 | §2 粒子 / §3 拖尾 / §4 发光 |
| 技能范围提示 | 贴地、持续、清晰边界 | 贴地 mesh/投影 + 边缘 Shader（非粒子，省 CPU） | §4 Shader |
| 状态持续效果 | 循环、低强度、长时 | 循环 Particle System（低发射率）+ looping 控制 | §2 粒子（CPU 预算） |
| 奖励演出 | 爆发、序列、庆祝感 | 爆发粒子 + 多系统错峰编排 + Bloom（高档机） | §2 / §5 Bloom |

> 判断条件：同屏多特效按 KB-025 §6 预算表控粒子总数与 OverDraw；范围提示优先 mesh/Shader 而非粒子（粒子吃 CPU，KB-025 §2.1）。

## 2. 命中特效完整拆解（基于 KB-025 组件的设计方法论）

**触发点**：伤害判定命中帧（攻击碰撞/技能命中回调）触发，非每帧；命中即播一次，短时长（0.2–0.5s 量级）。

**分层**（各层对应 KB-025 组件）：

| 层 | 作用 | 组件 | 时长 |
|----|------|------|------|
| 闪光层 | 瞬时强反馈 | Shader 发光 billboard 片（§4）或高亮 sprite | 极短（1–3 帧） |
| 粒子层 | 飞溅/碎屑方向感 | 爆发 Particle System，少量高速粒子（§2） | 短（0.2–0.4s） |
| 拖尾层（可选） | 运动轨迹 | TrailRenderer（§3），仅挥击/弹道类命中 | 随运动 |

**表现时序**：闪光先于粒子（闪光抓眼→粒子扩散）；粒子爆发后快速衰减；整体 0.5s 内结束避免拖沓。

**同屏降级**（KB-025 §6 预算）：
- 用 ParticleEffectProfiler 测单特效 Overdraw/DrawCall/粒子数（§3 工具）。
- 同屏多命中（群攻）：减粒子发射率、关拖尾层、闪光层合并；按 KB-025 §6.2 压测法定低端机上限。
- 注意 automatic culling 失效（非线性粒子运算致屏幕外仍更新，见 §3）。

> 本节是设计方法论（综合 KB-025 已核实技术组件），具体参数以项目压测为准，非外部固定标准。

## 3. 可复用工具与资源（gh api 核实 2026-11-14）

| 资源 | 星 | 许可证 | 内容 | 适用/版本 |
|------|----|--------|------|-----------|
| [sunbrando/ParticleEffectProfiler](https://github.com/sunbrando/ParticleEffectProfiler) | 524 | **MIT** | 特效性能分析：Overdraw/DrawCall/粒子数/内存显示在 scene + 折线图；automatic culling 失效检测；UWA 已集成 | README 列 Unity 5.x/2017/2019；**2022.3/团结兼容待验证** |
| [akof1314/UnityParticleSystemPreview](https://github.com/akof1314/UnityParticleSystemPreview) | 317 | **MIT** | 检视器内预览粒子（像动画预览），Play/AutoPlay/速度调节；Package Manager git URL 安装 | 活跃 2025-02；AssetStore 73346 |
| [keijiro/ShurikenPlus](https://github.com/keijiro/ShurikenPlus) | 138 | **无 LICENSE** | 粒子自定义 Shader 合集 | 2018 停更；**仅思路参考，不可直接复用** |

**ParticleEffectProfiler 用法**：相机对准特效（全覆盖屏幕，勿太近/远——Mipmap 太远有效像素少致 Overdraw 少算）→ 选中单个特效 → 右键「特效→测试」→ 自动运行记录 Overdraw/DrawCall/粒子数折线（默认 3s×30fps=90 点，循环特效勾选循环）。直接服务 KB-025 §6 预算验收。

**automatic culling 坑**（工具 README 引 [Unity 文档](https://docs.unity3d.com/ScriptReference/ParticleSystem-automaticCullingEnabled.html)）：粒子非线性运算致 Unity 无法实时取粒子位置，特效超屏幕仍更新无法自动剔除——同屏特效多时显著影响性能，KB-025 §2.1 CPU 预算需考虑。

## 4. 资源获取现状与边界（诚实记录）

- **GitHub 专用命中/范围特效素材仓库稀缺**：搜 unity hit effect / particle effect pack / skill indicator 多空或 0★ 个人练习；游戏 VFX 素材主要在 **Asset Store（付费）** 与视频教程。
- **可复用的是工作流工具**（预览/性能分析）而非现成特效素材；特效本体仍需按 §1/§2 用 Particle System 自制或购 Asset Store。
- **许可证纪律**：MIT 工具可复用；无 LICENSE 仓库（ShurikenPlus）默认保留所有权利仅参考；Asset Store 素材按各自 EULA（接入前走 [外部库选型评估](./外部库选型评估.md)）。
- **版本兼容**：ParticleEffectProfiler README 仅列 Unity 5.x-2019，本项目 2022.3/团结需装包验证（归 B 类待验证）。
