# 启动留存数据上报

适用：团结引擎 / Unity 2022.3 WebGL 微信小游戏（Unity Loader 转换链路）；IAA 买量留存分析。
触发：分析玩家点击→进核心玩法的流失漏斗、上报自定义启动阶段、区分广告渠道留存、获取 Loader 启动阶段耗时。
核对日期：2026-11-14（微信适配文档 Design/ReportStartupStat.md，经镜像 BlackTom900131/minigame-unity-webgl-transform gh api 取得；原页待浏览器复核）。
前置：启动指标定义（CALLMAIN/游戏初始化完成≈FP/游戏可交互完成≈TTI）见 [小游戏启动优化](./小游戏启动优化.md) §五；本条目讲上报 API 与数据获取。

## 结论速览

1. **Unity Loader 自动上报**代码包/首包资源/代码编译/引擎与首场景初始化（无需手动）；**自定义阶段 + 启动加载完成需主动调接口**。
2. **进核心玩法时调 `WX.ReportGameStart()`**（休闲进核心玩法、MMO 进创角）；自定义阶段用 `WX.ReportScene`，错误用 `WX.ReportGameSceneError`。
3. **买量带广告参数**（adSpaceType/adType/materialType，取值 1-200 默认 0）Loader 自动上报，区分广告位/类型/素材留存。
4. **数据报表需开通**「公众平台→能力地图→生产提效包→快适配」；看总体流失漏斗 + 分阶段耗时分布定优化方向。

## 1. 自动 vs 自定义上报

- **自动**：Unity Loader 自动统计代码包、首包资源、代码编译、引擎与首场景初始化，开发者无需关注。
- **自定义阶段 + 启动加载完成**：需开发者主动调接口（§3）。

## 2. 上报广告信息（买量分析）

广告买量时带自定义参数，Loader 自动上报，区分不同广告位/广告类型/素材类型：

```
adSpaceType=1&adType=1&materialType=1
```

- `adSpaceType` 广告位类型 / `adType` 广告类型 / `materialType` 素材类型；取值 **1-200，默认 0**。

## 3. 自定义阶段上报 API

```csharp
// 完成所有加载、进核心玩法时调（休闲进核心玩法 / MMO 进创角）
WX.ReportGameStart();

// 上报自定义阶段（如 Loading 中 A 资源完成 sceneId=1001，统计该环节留存）
WX.ReportScene(new ReportSceneParams {
    sceneId = 1001,
    costTime = 100,
    metric = new Dictionary<string,string>{ {"testkey1","1"} },
    dimension = new Dictionary<string,string>{ {"testkey1","testvalue1"} },
    complete = res => Debug.Log("complete " + res),
    success  = res => Debug.Log("success " + res),
    fail     = res => Debug.Log("fail " + res),
});

// 上报当前自定义阶段错误（errorType 取值 [0,10000]）
WX.ReportGameSceneError(sceneId, errorType, errStr, extJsonStr);
```

sceneId 同「启动场景上报分析」；详细见 [wx.reportScene](https://developers.weixin.qq.com/minigame/dev/api/data-analysis/wx.reportScene.html)、[启动场景上报分析](https://developers.weixin.qq.com/minigame/dev/guide/performance/perf-action-start-reportScene.html)（原页待浏览器复核）。

## 4. 获取 Loader 启动阶段（仅 JS）

业务侧需用 Loader 启动数据时，监听进度事件上报到自己系统：

```js
gameManager.onLaunchProgress = (e) => {
  // e.data: costTimeMs 阶段耗时 / runTimeMs 总耗时 / loadDataPackageFromSubpackage
  //         isVisible 前后台 / useCodeSplit 代码分包 / isHighPerformance iOS高性能
  if (e.type === launchEventType.compileWasm) { /* ... */ }
};
// launchEventType: launchPlugin 0 / loadWasm 1 / compileWasm 2 / loadAssets 3
//                  unzipAssets 4 / readAssets 5 / prepareGame 6
```

五阶段：wasm 代码包下载 → wasm 编译 → 首包资源下载 → 首包资源读取 → 引擎初始化（callmain）。

## 5. 获取数据报表

- **需开通**「公众平台→能力地图→生产提效包→**快适配**」后方可查看数据。
- 报表含自动上报 + 自定义阶段；关注**总体流失漏斗**定优化方向，**分阶段耗时分布**分析该耗时用户占比。
- 转换插件 < 202211101011（Unity Loader < 1.1.2）：报表需联系平台获取；数据未来开放到《小游戏数据助手》。
