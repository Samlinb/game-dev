# 微信与抖音小游戏发布检查

适用：微信小游戏、抖音小游戏；本工作区项目为团结引擎（Unity WebGL/Native）双平台，模板出包步骤见 [projects/MiniGameTemplate/docs](../projects/MiniGameTemplate/docs/build-wechat.md)。触发条件：出包前自查、提审被拒排查、核对包体/分包/资质是否达标。核对日期：**2026-11-11**（所有数值均当日打开官方现行文档核实，微信文档有字体反爬，经浏览器渲染读取）。

> **数值会随平台政策变化，用前必查官方原文。** 本条记录的是 2026-11-11 的官方口径；每项附来源与核对日期，超过一个季度或平台发公告后应复核。

## 自查顺序（第一步做什么）

1. **先量包体**：构建后看主包/总包大小，对照第一节硬约束表——微信主包 ≤4M、总包 ≤30M；抖音首包 <100M（推荐 <60M）。超限先做分包/压缩/远程化，再谈提审。
2. **过发布前 check**：抖音照第三节技术指标逐项核对（首场景下载 ≤10MB、进首场景 ≤5s 等）；微信核对分包配置与开放数据域约束。
3. **核前置资质**：微信类目/备案/软著（第四节），抖音账号与 AppID 校验（07 结尾 20 位）、安全约束（第五节）。
4. **走流程**：按第二节对应平台的「构建→送测/上传→提审→发布」入口执行，真机验证广告与首屏后再提审。

**怎样算通过**：包体在限额内、发布前 check 全过、资质齐备、真机广告三路径（看完发奖/中途关闭不发/onError 重建）走通——广告验收细则见模板 [build-wechat.md](../projects/MiniGameTemplate/docs/build-wechat.md) / [build-douyin.md](../projects/MiniGameTemplate/docs/build-douyin.md)。

## 一、包体与分包限制（硬约束）

### 微信小游戏

| 项 | 限制 | 适用条件 | 来源（核对 2026-11-11） |
| --- | --- | --- | --- |
| 代码包总大小 | **≤ 30M**（主包+所有分包） | 全部小游戏 | [代码包](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/code-package.html)「包大小限制」 |
| 主包 | **≤ 4M** | 首次启动必须下载的包 | 同上 + [分包加载](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/subPackage/useSubPackage.html) |
| 单个普通分包 | **不限制大小** | 配置在 `subpackages` 的目录/js | [分包加载](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/subPackage/useSubPackage.html)「分包加载包大小的限制」 |
| 单个独立分包 | **≤ 4M** | 独立分包（不依赖主包即可运行） | 同上 |
| 开放数据域目录 | **不能设为分包或置于分包下** | `openDataContext` 配置目录 | 同上「分包配置」注 |

**注意**：资源汇总里旧记的「总包 20M」已过时，现行官方为 **30M**（两页互证）。主包 4M 不变。

分包加载 API（[分包加载](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/subPackage/useSubPackage.html)，核对 2026-11-11）：
- `wx.loadSubpackage()`：下载分包**并自动执行**代码，返回 `LoadSubpackageTask` 可查进度。
- `wx.preDownloadSubpackage()`：**基础库 ≥ 3.4.9**，只下载不执行；预下载后仍需 `wx.loadSubpackage` 执行代码。
- 基础库 < 2.1.0 无 `loadSubpackage`，用 `require('分包入口.js')` 触发；微信 6.6.7 以下客户端开发版/体验版打不开分包小游戏（正式版不受影响）。

### 抖音小游戏

抖音分 **Native（仅 Android，APK）** 与 **WebGL（Android/iOS）** 两方案，包体口径不同：

| 项 | 限制 | 适用条件 | 来源（核对 2026-11-11） |
| --- | --- | --- | --- |
| 首包硬约束 | **Native < 100M；WebGL < 100M** | 上线准入（较宽松，先拿线上数据） | [Unity 小游戏接入指南](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/unity-game-access/install-connect/sc_access_guide)「阶段四」（文档更新 2025-06-11） |
| 首包推荐 | **< 60M**（32位+64位，关闭 StripEngineCode） | 体验推荐值 | [抖音Unity小游戏发布](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/unity-game-access/sc_publish)「使用必读」（更新 2025-12-11） |
| 优秀参考 | Native 20M / WebGL 10M | 转化率优化目标 | 接入指南「阶段四」 |
| 上传体积拦截 | **以 IDE 上传报错弹窗为最终依据** | 新包体格式 | [Unity包体格式更新](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/unity-game-access/install-connect/unity-new)「2.5 包体大小和压缩」（更新 2026-09-07） |

**抖音没有像微信那样公布固定的主包/总包 MB 数**——新包体格式的体积限制由 IDE 上传时校验，官方明确「以 IDE 上传时的报错弹窗为最终判断依据」。超限处理顺序：① 开启包体压缩（显著减小 wasm/data，平台对压缩文件有预下载/预解压处理，不显著影响启动）→ ② 仍超限则用 **Data CDN** 把 data-package 放自有 CDN 绕开包大小限制。（[Unity包体格式更新](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/unity-game-access/install-connect/unity-new) FAQ Q3，核对 2026-11-11）

**wasm 分包大小计算**：执行 wasm 分包后，`总包大小 = max(AndroidWasm分包, iOSWasm分包) + 其他包`，**不是**两平台分包相加——不必担心平台分包文件多占包体。（同上「2.5」，核对 2026-11-11）

**Wasm 分包工具**（[Wasm分包工具说明](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/open-capacity/performance-optimization/start-up/code-upload/sc_webgl_split)，更新 2026-08-26，核对 2026-11-11）：Unity WebGL 的 wasm 通常约 30M、Brotli 压缩后约 6M；工具把 wasm 拆成启动首包+延迟分包。入口在**抖音开发者工具 ≥ 4.3.2** 顶部工具栏；需真机预览收集函数（覆盖启动后最先进入的场景/关卡），发布到线上后自动开启线上函数收集。

## 二、发布流程与检查入口

### 微信

版本类型（[代码包](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/code-package.html)「版本类型」，核对 2026-11-11）：**开发版**（预览生成、扫码获得、每个开发者本地一个）→ **体验版**（后台将开发版设为体验版，全游戏一个）→ **正式版**（线上，一个）。

流程：微信开发者工具**上传**代码 → [mp.weixin.qq.com](https://mp.weixin.qq.com) 后台**版本管理** → 设为体验版真机验证 → **提交审核** → 审核通过后**发布**。（版本类型与上传入口为官方文档核实；后台提审/发布按钮位置以 mp 后台实际界面为准。）

代码包缓存：下载后缓存供离线打开，清理时机由算法动态计算；用户在历史列表删除小游戏（下拉任务栏删除不算）或设置-通用-存储空间清缓存时主动清理。（同上「缓存与清理机制」）

### 抖音

流程（[抖音Unity小游戏发布](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/unity-game-access/sc_publish)，更新 2025-12-11，核对 2026-11-11）：

1. **构建**：TTSDKTools → Build。
2. **送测**：TTSDKTools 或抖音开发者工具发布 **latest** 版本到测试环节。
3. **提审**：登录抖音开放平台 → **版本管理** → 测试完毕 → **提交审核**。
4. **发布**：审核通过 → 版本管理 → **发布**。

工具版本要求：抖音开发者工具 **≥ 4.2.2**、TTSDK **≥ 6.2.0**（发布页）；新包体格式需要开发者工具 **≥ 4.4.3**、调试基础库 **≥ 3.77.0.0**、抖音客户端 **≥ 35.0.0**（包体格式更新页）。**TTSDKTool 自 4.0.2 起不再支持发布**，迁移到抖音开发者工具。

关键检查点（同上，核对 2026-11-11）：
- **AppID 校验**：数字结尾必须是 **07**，长度 **20 位**，否则重新申请。
- **版本号**必须大于当前测试版本；可「获取可发布版本号」自动 +1。
- **测试通道**：最多同时 25 个测试版本（默认通道 + 通道 1–24）；同版本号+同通道号不可覆盖。多测试版本仅支持抖音/抖音极速版/抖音火山版（**≥ 31.6.0**），其他宿主只打开默认通道。
- **真机调试前必须先发布过一次版本**，否则报错（[旧版StarkSDK迁移指南](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/unity-game-access/install-connect/starksdkmigrationguide/sc_stark_sdk) FAQ）。

## 三、发布前 check（抖音官方技术指标）

来源：[旧版StarkSDK迁移指南](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/unity-game-access/install-connect/starksdkmigrationguide/sc_stark_sdk)「发布前check」（核对 2026-11-11）：

- 启动后**建议下载 ≤ 10MB 资源**即可进入首场景。
- 启动后**建议进首场景时间 ≤ 5s**。
- 包名**不要以 `.miniapk` 结尾**。
- 处理多宿主表现：**非抖音环境不显示「关注抖音号」提示及入口**。
- 「关注抖音号」功能需**日活 ≥ 100** 才能开通，未开通前入口先关闭。
- 在小程序开发平台注册项目、开通激励视频广告等能力。

## 四、前置资质与内容红线（微信）

| 项 | 要求 | 来源（核对 2026-11-11） |
| --- | --- | --- |
| 类目 | 选**游戏类目后不可改为其他小程序类目**；按属性选对二级类目，不得借他类规避管理 | [运营规范](https://developers.weixin.qq.com/minigame/product/)「3.1 游戏类目选择规范」 |
| 资质 | 提供国家法律法规要求的各类资质文件；软著对外授权须提供完整授权文件，腾讯按授权确定唯一发布主体 | 同上 |
| 备案 | 新增小程序 2023-09-04 起开放备案入口；依《反电信网络诈骗法》第23条等须履行备案；游戏属前置审批类目（网络游戏上网出版须出版行政主管部门审批） | [小程序备案操作指引](https://developers.weixin.qq.com/minigame/product/record/record_guidelines.html) |
| 同质化 | 不得提交与后台模板相似度过高、抄袭、或仅换美术/UI 的多个玩法一致小游戏 | 运营规范「3.1」「2.1 注册提交规范」 |
| 现金红包 | 打开红包/提现**不得设任何附加条件**（禁止要求分享、看视频广告、限额提现、关注公众号/下载 APP 提现等） | 运营规范「3.2.5 游戏功能」 |
| 涉赌/诱导 | 不得提供赌博玩法、用户间定向转移道具、币商信息；不得以随机抽取诱导投入法定/虚拟货币 | 同上 |

**对广告变现休闲游戏的直接影响**：激励视频发奖本身合规，但「看广告才能提现/开红包」触碰现金红包红线；「看广告发游戏内金币」属正常激励视频，不在此列。拿不准时对照运营规范原文。

## 五、安全与 SDK 约束（抖音）

来源：[接入指南](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/unity-game-access/install-connect/sc_access_guide)「阶段二」+ [发布](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/unity-game-access/sc_publish)「使用必读」（核对 2026-11-11）：

- **不允许原生 Java 代码库**；Native 方案须删除 `Assets/Plugins/Android` 下 java/jar/aar，不支持 JNI 调用。
- C++ 插件须**以源码形式**放工程内，so 文件做安全扫描；有限支持部分开源且著名的第三方 so。
- **不支持接入其他平台商业化 SDK**（广告/登录/支付），接入前删除——同时降包体。
- 对抖音有破坏性行为会**封停账号**并保留司法追责。
- 创建游戏时选「Unity 引擎」后，**无法在普通小游戏引擎与 Unity 引擎间转换**。

## 六、引擎/资源侧出包自查（两平台通用，模板已落地）

与 [Unity 小游戏项目架构](<./Unity 小游戏项目架构.md>)「渲染与资源出包口径」一致，模板 `docs/build-*.md` 已列：纹理 ASTC、音频 AAC 低码率/强制单声道、BGM 远程 CDN 不进首包、Managed Stripping ≥ Low + `link.xml`、Gamma 色彩空间。抖音官方另建议（[性能优化总览](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/open-capacity/performance-optimization/sc_webgl_performance_optimization)，更新 2025-05-27，核对 2026-11-11）：单个 AB 推荐 ≤ 2MB、资源请求并发 ≤ 20（经验值）、贴图 maxsize ≤ 1024 且不生成 Mipmap/不可写、字体压缩前 ≤ 4MB、CDN 必须开压缩、首场景 Awake/Start/首帧 Update 不放重逻辑。
