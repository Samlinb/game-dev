# 小游戏资质与类目（微信 + 抖音）

适用：微信小游戏、抖音小游戏发布前的资质准备。本工作区项目为 IAA（广告变现）2D 休闲游戏。
触发：提审被拒要求补资质、首次发布准备材料、判断是否需要版号/软著。
核对日期：2026-11-12（微信 IAA/IAP 资质审核页 + 备案页 + 运营规范，WebFetch 直接取到正文）。

## 结论（影响行动的部分）

1. **IAA 休闲游戏不需要版号**。版号（网络游戏出版物号核发单）是 IAP（虚拟支付）的必填项；IAA 走「情况二：当前及未来均不需要开通虚拟支付」，无版号要求。
2. **IAA 软著通常不需要**。仅当游戏名称含英文或"软件"字样、或涉及品牌/公众人物合作时才需提交软著或授权材料。
3. **备案是必须的**。IAA 游戏备案 = 前置审批（资质审核）+ 小程序备案（工信部）。企业主体须先完成微信认证。
4. **类目选定后不可更改为其他小程序类目**。二级类目按游戏属性选，不得借他类规避管理。
5. **抖音侧资质要求待核对**（本轮未取到抖音运营规范正文）。

## 一、微信：IAA vs IAP 资质对比（官方规定）

| 项 | IAA（广告变现） | IAP（虚拟支付） |
|----|----------------|----------------|
| 版号 | **不需要** | **必填**（网络游戏出版物号核发单） |
| 软著 | 仅特定条件需要（见下） | **必填**（计算机软件著作权登记证书） |
| 授权书 | 同上特定条件 | 可选（运营授权书/著作权授权书） |
| 备案情况 | 情况二 | 情况一 |
| 支付资质 | 不申请 | 同时申请 |
| 审核时限 | 1–3 自然日 | 1–3 自然日 |

来源：
- [资质审核-IAA](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html)，核对 2026-11-12。
- [资质审核-IAP](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iap.html)，核对 2026-11-12。

### IAA 软著触发条件

以下两种情形才需提交软著或授权材料：
1. 游戏名称包含**英文**或"**软件**"字样。
2. 涉及**品牌、公众人物合作**等情形。

**对本项目的判断**：模板游戏名为中文、无品牌合作 → 不需要软著。若后续改名含英文（如 "XX Runner"），则需补软著。

## 二、微信：备案流程（官方规定）

来源：[小游戏备案](https://developers.weixin.qq.com/minigame/introduction/guide/nrjs.html)，核对 2026-11-12。

### 两种情况

| 情况 | 适用 | 前置审批 |
|------|------|----------|
| 情况一 | 已有版号 / 计划开通虚拟支付（IAP） | 版号核发单 + 软著 |
| 情况二 | 当前及未来均不开通虚拟支付（IAA） | 按 IAA 资质审核提交 |

**已有版号的游戏无需再提交小游戏备案**，应返回选择情况一。

### IAA 备案全流程

```
1. 微信认证（企业主体必须）
2. 资质审核（情况二）→ 1-3 自然日
3. 适龄提示设置
4. 小游戏备案提交（内容说明 + 截图）
   → 平台初审 1-2 工作日
   → 主管部门审核 10-20 工作日（此阶段禁止任何修改）
5. 前置审批通过 → 进入小程序备案（工信部）
   → 填写备案信息 → 平台初审 → 工信部短信核验 → 通管局审核 → 备案成功
6. 版本审核 + 发布
```

**总时效**（接入指南）：IAA 预计 13–37 工作日；IAP 预计 9–22 工作日。
来源：[小游戏接入指南](https://developers.weixin.qq.com/minigame/introduction/guide/)，核对 2026-11-12。

### 常见驳回原因

- 游戏名称/签署主体与当前游戏不符
- 主体表述矛盾（"个人"与"我司"并存）
- 公章模糊或误用合同章/财务章/电子章
- 签名非本人、连笔签/铅笔签
- 缺签署日期或年月日不完整
- 同名游戏已获批（须改名，新名称与玩法题材有关联）
- 截图尺寸/版本不一致

### 注意事项

- 主管部门审核阶段**禁止任何修改**（包括改名、主体迁移）。
- 备案完成后才能改名/改主体，改后须同步更新备案信息。
- 长期不完成工信备案或信息不符 → 可能被限制搜索、限制新用户注册。

## 三、微信：类目选择规范（官方规定）

来源：[运营规范 3.1](https://developers.weixin.qq.com/minigame/product/)，核对 2026-11-12。

1. 选择游戏类目后**不可修改变更为其他小程序类目**。
2. 应提供国家法律法规要求的各类资质文件。
3. 不得提交与后台模板高度相似/抄袭的小游戏；不得仅换美术/UI 提交多个玩法一致的小游戏。
4. 著作权对外授权须提供完整授权文件；多主体运营以先提交者为准。
5. 二级类目按游戏属性选择，不得以其他类目规避管理。平台有权变更类目种类和准入要求。

## 四、微信：个人主体限制（部分核实）

已核实：
- 接入指南全文只提及"企业主体"，企业主体必须微信认证才能备案。
- 小程序类目表中个人主体开放 8 类（物流/教育/生活服务/餐饮/旅游/工具/商业服务/体育），**不含游戏**。

**推断**（待官方确认）：个人主体不能选择游戏类目发布小游戏。本项目需企业主体。

## 五、微信：内容红线（官方规定）

来源：[运营规范](https://developers.weixin.qq.com/minigame/product/)，核对 2026-11-11（发布检查条目已核实）。

| 红线 | 说明 |
|------|------|
| 现金红包 | 打开红包/提现不得设任何附加条件（禁止分享/看广告/限额提现等） |
| 涉赌 | 不得提供赌博玩法、用户间定向转移道具、币商信息 |
| 诱导 | 不得以随机抽取诱导投入法定/虚拟货币 |
| 同质化 | 不得仅换美术/UI 提交多个玩法一致小游戏 |

**对 IAA 休闲游戏的影响**：激励视频发游戏内金币合规；「看广告才能提现/开红包」触碰红线。
