# 小游戏免广告方案与 IAA 变现优化（微信 + 抖音）

适用：纯 IAA（广告变现）、无虚拟支付的小游戏，运营机制设计与广告位策略。
触发：想给用户提供免广告权益但不损失收入、设计免广告卡/券、插屏打扰过多想降频、评估广告点位改造。
核对日期：2026-11-12。核实程度见[来源与核实状态](#来源与核实状态)。

## 核心原则（影响行动的部分）

1. **免广告 ≠ 免掉全部广告**。免掉的是低价值、打扰型广告（插屏/横幅），保留高价值、自愿型广告（激励视频）。
2. **激励视频 eCPM 通常为插屏的 2~5 倍**（行业经验值，未按平台/时段核实）。因此「看激励视频换免插屏」是把广告库存从低价格式换到高价格式，收入往往不降反升。
3. 免广告权益的真正收益在留存：体验变好 → DAU 与时长上涨 → 总曝光上涨。IAA 游戏收入 ≈ DAU × 人均曝光 × eCPM，前两项比 eCPM 更可控。

## 五个机制（按推荐顺序）

### 1. 看广告换免广告时长（核心机制）

- 看完 1 次激励视频 → 获得「30 分钟免打断广告」或「10 局免插屏」。
- **免广告范围只含插屏 + 横幅；激励视频入口永远保留**——那是收入主力。
- 设计要点：权益生效期间结算页/复活页的激励视频按钮照常展示，仅隐藏被动弹出的插屏和常驻横幅。

### 2. 免广告券做成游戏内道具，走软通货

- 获取渠道：签到、每日任务、成就、通行证等级、礼包码。→ 拉留存，DAU 上涨带动总曝光。
- 也可在游戏内商城/补给站用金币、钻石等软通货购买 → 软通货回收渠道，增强经济循环。
- 注意：用软通货而非现金购买（无支付资质的前提），且不得设计成「法定货币间接买免广告」的违规通道。

### 3. 分层运营（平台官方能力，正文待核对）

- 微信「开放能力→广告」下存在 **IAA 预测组件**（预估单个用户的广告价值）与**流量主广告金**（现金补贴）。抖音有类似用户价值分层能力（未核实名称）。
- 用法：高广告价值用户减少插屏保体验（他们的留存值钱）；低价值用户维持正常密度；新用户前 N 局免插屏（新手保护，先养留存再上广告）。

### 4. 「少而贵」的频控优化

- 插屏加冷却：每 3 局最多 1 次、战斗/对局中不弹、单日上限（如 10 次）。
- 聚合竞价（GroMore / TopOn，穿山甲+优量汇+快手同台竞价）拉高整体 eCPM → 同样收入所需曝光更少，免广告更「舍得」。
- 点位改造：把打断式插屏点位改造成激励式——复活看视频、双倍结算看视频、免费抽一次看视频。

### 5. 社交裂变换免广告

- 邀请好友 / 分享得免广告券 → 新增用户产生的广告收入覆盖让利，附带一个自然量获取循环。
- 红线提醒：分享奖励本身合规，但不得强制分享才能继续游戏（平台运营规范对强制分享有限制，待核对具体条款）。

## 设计细节决策表

| 决策点 | 建议 | 理由 |
|--------|------|------|
| 时长型 vs 次数型 | 混合：局数为主、时长为辅 | 时长型体验好，次数型可控可核算 |
| 有效期 | 券设 24h 过期 | 制造回访理由，拉次日留存 |
| 叠加上限 | 单日免广告时长封顶（如 2 小时） | 防止重度用户零曝光 |
| 状态存储 | 服务端/云开发存储，客户端只读 | 防改本地时间、改存档白嫖 |
| 新手期 | 前 5~10 局免插屏 | 先养留存再上广告，首日留存直接影响买量回收 |
| 弹出时机 | 插屏只在局间结算后，绝不在对局中 | 对局中弹插屏是流失首因（经验值） |

## 风控与结算

- 奖励发放用平台回调判定：微信激励视频 `onClose` 回调 + `isEnded`；抖音同理。
- 微信「开放能力→广告」下有**激励广告反作弊**能力与**广告数据接口**（可对账曝光/结算）。接入时启用，防止刷激励视频。
- 免广告券的发放/消耗流水进埋点，便于核算「免广告期间曝光损失 vs 留存收益」。

## 内容红线关联

激励视频发游戏内金币、道具、免广告券均合规；「看广告才能提现/开红包」触碰现金红包红线（详见[小游戏资质与类目](./小游戏资质与类目.md)第五节）。

## 落地到 IAA 休闲项目（检查清单）

- [ ] 盘点现有广告点位，标注类型（插屏/横幅/激励）与触发时机
- [ ] 插屏加冷却与单日上限，对局中禁弹
- [ ] 结算页/复活页保留激励视频入口
- [ ] 新增「免广告券」道具：签到/任务发放 + 软通货购买
- [ ] 免广告状态服务端存储，仅屏蔽插屏+横幅
- [ ] 接入 IAA 预测组件（微信）做用户分层，验证后再调密度
- [ ] 埋点：免广告券发放/消耗/免广告期间时长，核算 ROI
- [ ] 接入聚合竞价（若当前为单广告源），对比 eCPM 变化

GardenBattle 项目参照：补给站重设计（docs/12）可直接承载「免广告券」货架；插屏点位已有空白位待填。
