# 写新功能前先找现成实现

适用于任何引擎和平台；触发条件是准备实现一个非琐碎的通用能力——寻路、Tween 缓动、对象池、序列化、依赖注入、UI 框架这类多数项目都会遇到的功能。20 行以内的胶水代码、一次性调试脚本、以学习为目的的实现不适用本条（20 行是经验阈值，按项目调整）。

## 为什么成立

四个支撑这条规则的工程事实：

- **代码是负债，不是资产。** 自研代码的寿命成本主要是维护：测试、兼容升级、安全补丁、接手人的理解成本。成熟开源实现把这些成本摊给整个社区，自研则由本项目独自承担，而维护通常比首次编写更昂贵。
- **大多数"新功能"是被解决的问题。** 先搜几分钟再动手，换来的是免除数天自研开发加长期维护成本；这是规则的收益模型。
- **自研有固定翻车区。** 密码学、身份验证、时间与时区、Unicode 处理、并发边界——重新实现几乎必然引入边界 bug。
- **拒绝外部方案常常是心理偏误而非工程判断。** NIH（Not Invented Here）综合症指组织回避使用外部成果的倾向，成因包括部落心理、不理解外部工作、不愿承认他人价值；Katz & Allen（1982）发现 R&D 项目组随时间变得封闭、与外部信息源沟通减少，绩效随组龄下降；对应的健康做法是 "proudly found elsewhere" 开放创新。 [Not Invented Here](https://en.wikipedia.org/wiki/Not_invented_here)（核对 2026-11-11）

## 搜索顺序

按维护保障从强到弱依次查，命中即停：

1. **本项目已有实现**。同类依赖不要引两份；先查仓库内代码和 [经验包](../experience-packs/)。
2. **引擎官方包**。Unity 走 Package Manager：Registry 与 Built-in 源由 Unity 维护，带语义化版本、依赖解析和版本冲突处理；Cocos Creator 内置扩展商店，编辑器菜单 **扩展 → 商城**，网页入口 [store.cocos.com/app](https://store.cocos.com/app/)，可浏览、下载并自动安装官方/第三方扩展与资源。 [upm-concepts](https://docs.unity3d.com/2022.3/Documentation/Manual/upm-concepts.html) · [Cocos 主菜单说明](https://github.com/cocos/cocos-docs/blob/master/versions/3.8/zh/editor/mainMenu/index.md)（核对 2026-11-11）
3. **GitHub 搜索**。语法见下节。
4. **精选清单与商店**。awesome-unity 等 awesome 列表、Asset Store、itch.io（素材与小工具）。此层来源未逐项核实，命中后仍走评估清单。

## GitHub 搜索语法（核对 2026-11-11）

来源 [Searching for repositories](https://docs.github.com/en/search-github/searching-on-github/searching-for-repositories)。默认只搜名称、描述和 topics；限定符可任意组合，不区分大小写，多词加引号：

| 限定符 | 作用 | 示例 |
| --- | --- | --- |
| `stars:` | 星数过滤 | `stars:>=500` |
| `language:` | 代码语言 | `language:c#` |
| `topic:` | 社区打的主题标签 | `topic:unity` |
| `pushed:` | 最近推送日期，筛活跃度 | `pushed:>2026-01-01` |
| `in:` | 扩大搜索范围 | `in:readme` / `in:name` / `in:description` |
| `archived:` | 排除已归档仓库 | `archived:false` |
| `license:` | 按许可证过滤 | `license:apache-2.0` |
| `org:` / `user:` / `forks:` / `size:` | 收敛主体与规模 | `org:ORGNAME`、`forks:>50` |

组合示例：`object pool stars:>=100 language:c# topic:unity pushed:>2026-01-01 archived:false`

## 例外边界：这些情况直接自写

| 条件 | 判断 |
| --- | --- |
| 胶水代码 | 20 行以内且无可复用价值：搜索加评估的成本高于自写 |
| 依赖膨胀 | 只用候选库 5% 的功能却引入整个框架；小游戏平台还要付包体代价 |
| 候选质量不足 | 停维、无测试、单人维护且 issue 无人应 → 走 [外部库选型评估](./外部库选型评估.md) 逐项核对 |
| 许可证冲突 | 闭源商业项目引入 GPL/AGPL 族代码 |
| 学习目的 | 自己实现就是任务目标，可先写一遍再对照成熟实现 |

## 规则的完整形态：搜索 → 评估 → 四选一

"不要重复造轮子"的前半句是先搜索，后半句是评估后决策——引入外部代码同样有代价，省略后半句在历史上出过三次已核实的事故：

- **left-pad（2016-03）**。作者与 Kik 的包名争议发酵后删除了自己全部 272 个 npm 包，其中 11 行的 left-pad 经 babel 等依赖链放大，数千项目构建失败，每分钟数百次报错，npm 破例用备份重新发布才恢复，中断共 2.5 小时。教训：依赖链越深，单个微小环节越是单点。 [npm 官方复盘](https://blog.npmjs.org/post/141577284765/kik-left-pad-and-npm)（核对 2026-11-11）
- **event-stream（2018-11）**。停维的热门包被原维护者转交给主动来信的陌生账号，新维护者加入的 flatmap-stream 依赖携带加密载荷，只在 Copay 比特币钱包环境中解密激活，窃取钱包凭据与私钥。教训：无人维护的流行包被转手，等于把信任链交给陌生人。 [原始 issue](https://github.com/dominictarr/event-stream/issues/116)（核对 2026-11-11）
- **xz 后门（2024-03）**。"Jia Tan" 账号自 2021 年起用数个马甲账号向原维护者施压并建立信任，获得维护权限后于 2024 年 2 月把劫持 sshd 认证的后门藏进 5.6.0/5.6.1 源码包（CVE-2024-3094，CVSS 10）；后门靠测试文件与 configure 脚本注入、仅在极窄条件下激活，被 Andres Freund 因 ssh 登录耗 CPU 与 valgrind 报错追查发现。教训：维护权本身是供应链的信任锚点。 [披露原文](https://www.openwall.com/lists/oss-security/2024/03/29/4) · [XZ backdoor](https://en.wikipedia.org/wiki/XZ_backdoor)（核对 2026-11-11）

决策落在四选一，每个选择要能说出理由：**接入**（评估通过）· **fork 自维护**（代码可用但维护方不可靠或需本地改造）· **最小自写**（评估不通过且需求小）· **不做**（现有方案的维护成本超过功能价值）。

## 现成框架参考（D 方向挖掘，round 35）

搜「unity game framework」（宽词比窄词命中率高）找到的成熟框架，作选型参照：

| 框架 | stars | 说明 | 小游戏适用性 |
|------|-------|------|--------------|
| [EllanJiang/UnityGameFramework](https://github.com/EllanJiang/UnityGameFramework) | 2597 | 19 内置模块（对象池/资源异步加载/UI/声音/本地化/网络/流程 FSM/下载/Web 请求等），官网 gameframework.cn | **重型全家桶**——小型 2D 休闲小游戏慎用，模块冗余可能 overscoping（见独立项目范围管理）；中大型项目或需完整模块时参考 |
| [DangoRyn/UnityGameFramework_HybridCLR](https://github.com/DangoRyn/UnityGameFramework_HybridCLR) | 232 | GameFramework + HybridCLR + luban 热更与配置演示 | 需热更时参考（本项目 HybridCLR 见 WebGL坑条目） |

**判断**：本工作区模板（MiniGameTemplate）是轻量自研架构（IPlatformService/ResManager/PrefabPool/UIManager），小型小游戏优先轻量模板而非重型框架；GameFramework 作模块设计参照与中大型项目候选。接入前走 [外部库选型评估](./外部库选型评估.md)（许可证/维护活跃度/供应链）。
