# 微信构建模板定制

适用：团结引擎 / Unity 2022.3 WebGL 微信小游戏（WXSDK 转换链路）。
触发：定制 minigame 导出产物（game.js/game.json/脚本/图片）、随项目托管定制内容、避免 SDK 更新覆盖丢失。
核对日期：2026-11-14（微信适配文档 Design/BuildTemplate.md，经镜像 BlackTom900131/minigame-unity-webgl-transform gh api 取得；原页待浏览器复核）。
前置：导出包体结构见 [Unity WebGL 小游戏特有技术坑](<./Unity WebGL 小游戏特有技术坑.md>) §5；启动封面 loadingPageConfig 见 [小游戏启动优化](./小游戏启动优化.md) §4.2。

## 结论速览

1. **勿直接改基础模板 `wechat-default`**：SDK 更新会覆盖丢失修改。定制走 **`Assets/WX-WASM-SDK-V2/Editor/template/minigame`** 目录，按层级覆盖到导出 minigame。
2. **修改基准是 wechat-default（含占位符）**，不是导出产物 wechat/minigame（占位符已替换）——以基础模板为基准才能适应占位符替换。
3. **JSON 配置合并**：template/minigame 放 game.json/project.config.json 只填关注字段，自动合并（KV 末位新增/覆盖，Array 整节点替换）。
4. **覆盖关键脚本（.js/.json）后新版 SDK 会冲突警告**（初始化检查 + 导出时终止），需自行适配消除。

## 1. 构建模板机制

- 基础模板 `wechat-default` 位置：Package Manager 导入 `Packages/com.qq.weixin.minigame/Runtime/wechat-default`；Assets 导入 `Assets/WX-WASM-SDK-V2/Runtime/wechat-default`。**不建议编辑**（SDK 更新覆盖丢失）。
- 手动创建 `Assets/WX-WASM-SDK-V2/Editor/template/minigame/`，其中资源按完整层级覆盖到最终导出 `minigame` 目录（基础模板 + template 合并）。
- **修改基准**：wechat-default 含大量占位符（导出时按项目替换），不是可运行标准代码包；自定义脚本应以 **wechat-default 脚本为基准**，而非导出产物 wechat/minigame。

## 2. JSON 配置合并

template/minigame 放 `game.json` / `project.config.json`，**只填关注字段**，自动合并：
- **Key-Value**：末位节点新增或覆盖（如仅改 `plugins.UnityPlugin.version`）。
- **Array**：整节点新增或覆盖（如 `subpackages` 整体替换）。

```json
// template/minigame/game.json（只填关注字段）
{
  "test": "abc123",                       // 新增字段
  "plugins": { "UnityPlugin": { "version": "1.2.52" } },  // 仅变更版本号
  "subpackages": [ "..." ]                // 数组整节点替换
}
```

> 启动封面 loadingPageConfig 等 game.js 样式定制同理走 template 覆盖（启动优化 §4.2），勿直接改 wechat-default。

## 3. 新版 SDK 冲突提醒

覆盖过 wechat-default 关键脚本后，新版 WXSDK 导入会检测冲突（**只查 .js/.json，图片不查**）：
- WXSDK 初始化时（引擎启动/导入新 SDK）：控制台给详细冲突信息。
- 导出微信小游戏时：检测到冲突**终止导出** + 控制台冲突信息。
- **消除**：按提醒对比冲突脚本自行适配；自定义模板文件较冲突前变化后提醒自动消除。

## 4. 构建钩子（复杂定制）

简单覆盖不够时，用 C# 钩子：创建 `Assets/WX-WASM-SDK-V2/Editor/template/plugin.cs`（Editor 子目录，成员函数 public），继承 `LifeCycleBase`：

```csharp
public class PluginDemo : LifeCycleBase {
    public override void beforeCopyDefault() {
        // 可 throw Exception 阻止继续构建导出
    }
    public override void afterCopyDefault() { /* ... */ }
    public override void beforeCoverTemplate() {
        var tmp = BuildTemplateHelper.CustomTemplateDir;  // 动态改自定义模板
        // 导出结束后 WXSDK 自动还原修改，不影响工程托管
    }
}
```

**BuildTemplateHelper 三目录绝对路径**：`BaseDir`（wechat-default 标准模板）/ `CustomTemplateDir`（template/minigame 自定义）/ `DstMinigameDir`（wechat/minigame 导出产物）。可在钩子里新建脚本、正则局部替换、改图片；导出期间改自定义模板，导出后自动还原（便于代码托管）。
