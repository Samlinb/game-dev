# 平台能力开通与接入检查（微信 + 抖音）

适用：团结引擎 / Unity WebGL 小游戏，微信 + 抖音双平台。本工作区模板为 IAA 2D 休闲游戏。
触发：首次接入平台 SDK、开通广告变现、提审前能力自查、新增平台能力。
核对日期：2026-11-12（SDK 安装/构建流程/团结版本要求）；2026-11-13 round 25 经镜像+SDK 源码核实流量主 UV>1000 门槛与 WX SDK C# API 签名（§二/§三）。抖音广告开通条件仍待核对。

## 结论（影响行动的部分）

1. **模板已预留 4 个平台能力的完整骨架**（Login/ShowRewardedVideo/VibrateShort/ShareApp），接 SDK 只需填 TODO，不需改架构。
2. **微信 SDK 通过 Package Manager git URL 安装**；抖音 SDK 团结 ≥1.5 内置（BuildSettings → Install Support）。
3. **广告位 ID 必须先开通流量主才能创建**。流量主需**上线并累计 UV>1000**（镜像核实，§二）；广告接口需上线后才能调试。
4. **广告必须真机验证**：开发者工具内不出真实广告。三条路径（看完发奖/中途关闭/onError 重建）都要走通。
5. **编译符号切换平台**：`WECHAT_SDK` / `DOUYIN_SDK` 二选一，编辑器恒走 Stub。

## 三、SDK 安装（官方规定，已核实）

### 微信：minigame-tuanjie-transform-sdk

来源：[GitHub 仓库 README](https://github.com/wechat-miniprogram/minigame-tuanjie-transform-sdk)，核对 2026-11-12。

```
Unity Editor → Window → Package Manager → + → Add package from git URL:
https://github.com/wechat-miniprogram/minigame-tuanjie-transform-sdk.git
```

**已知坑**：空项目或未使用 WXSDK Runtime 能力时，团结引擎会裁剪微信 Runtime 包，导致导出后在微信开发者工具报错。解决：在游戏中合理位置增加对 WXSDK 的调用。

**C# API 签名（已核实，round 25）**：
- **命名约定**：JS `wx.xxx` → Unity `WX.Xxx`（wx→WX，方法名首字母大写）。来源：镜像 Design/WX_SDK.md。
- **初始化**：`WX.InitSDK((int code)=>{ /* 主逻辑 */ })`，回调后再执行主逻辑。
- **WX.cs 真实签名**（SDK 仓库 Runtime/WX.cs，gh api 核实 2026-11-13）：`WX.Login(LoginOption callback)`、`WX.VibrateShort(VibrateShortOption callback)`、`WX.ShareAppMessage(ShareAppMessageOption option)`、`WX.GetWindowInfo()→WindowInfo`。
- **广告**：`WX.CreateBannerAd(new WXCreateBannerAdParam(){ adUnitId, adIntervals, style=new Style(){left,top,width,height} })`，返回对象 `.OnLoad(()=>...)`/`.Show()`/`.OnError((WXADErrorResponse res)=>...)`；激励视频同模式 `WX.CreateRewardedVideoAd(...)`（精确 param 类型装 SDK 后核对，KB-012）。
- **版本兼容**：`WX.CanIUse("ReportScene")` 判断当前基础库是否支持某 API。
- 完整 API 见 SDK 仓库 `Runtime/WX.cs`（含详细注释）；安装后按编译报错对齐。→ KB-012。

### 抖音：团结内置插件 / StarkSDK

来源：[团结 DouyinSDK 手册](https://docs.unity.cn/cn/tuanjiemanual/Manual/DouyinSDK.html)，核对 2026-11-12。

| 团结版本 | 安装方式 |
|----------|----------|
| **≥ 1.5** | 内置。`File → BuildSettings → Install Support`。支持随时更换 SDK 版本。 |
| ≤ 1.4 | 先装 BGDT 平台，再下载 TTSDK。**顺序不可颠倒**。 |

BGDT 安装指引：[抖音 BGDT handbook](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/game-engine/rd-to-SCgame/BGDT-handbook/install)

**TT.* API 参考 demo（D 方向挖掘，round 28）**：[AnranS/tiktok-minigame-unity-demo](https://github.com/AnranS/tiktok-minigame-unity-demo)（8★，TTSDK v1.1.1，Unity 2022.3）——按 14 类分组暴露全部 `TT.*` API、按钮点击 + 回调日志面板、双语注释、含可导入 unitypackage 与 Editor mock（ttsdk-editor.dll）。**仅作 API 用法参考**：README 明确警告「Do not use the Tuanjie/团结引擎 fork — the SDK's asmdef will collide」，本项目用团结引擎，**SDK 本体不兼容团结**，仍用团结内置抖音插件/StarkSDK；TT.* API 签名以此 demo + 装 SDK 后核对（KB-012）。

### 广告真机验收标准（两平台通用）

| 路径 | 操作 | 预期 |
|------|------|------|
| 看完发奖 | 完整观看激励视频 | `isEnded == true` → 回调 true → 发奖 |
| 中途关闭 | 播放中点关闭 | `isEnded == false` → 回调 false → 不发奖 |
| 错误重建 | 断网/无库存触发 onError | 实例销毁重建 → 下次 show 正常 |
| show 失败重试 | 首次 show 失败 | 自动 load → 再 show → 仍失败才回调 false |

**激励视频三要素的决策逻辑**见 [Unity 小游戏项目架构](<./Unity 小游戏项目架构.md>)「激励视频为什么必须三件事」节（含 JS 参考实现）。

## 五、登录流程要点

```
客户端 wx.login / tt.login → code
    → 自家服务端 code2session → openid + session_key
    → 客户端只拿 code，不落 openid
```

- 微信：[登录文档](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/login.html)（需浏览器）
- 抖音：`tt.login` 同形状
- 模板 `Login(Action<string> onCode)` 只负责拿 code，服务端换取逻辑不在客户端。
