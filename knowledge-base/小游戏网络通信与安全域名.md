# 小游戏网络通信与安全域名

适用：团结引擎 / Unity 2022.3 WebGL 构建，微信 + 抖音小游戏平台。
触发：配置服务器安全域名、真机网络请求异常（工具正常真机失败）、接 HTTP/TCP/WebSocket/UDP 通信、上线前网络合规检查。
核对日期：2026-11-13（微信 Unity 适配文档 Design/UsingNetworking.md，经镜像 BlackTom900131/minigame-unity-webgl-transform gh api 取得；原页待浏览器复核）。
前置：System.Net 限制与基本映射见 [Unity WebGL 小游戏特有技术坑](<./Unity WebGL 小游戏特有技术坑.md>) §3.5；平台网络抽象见 [Unity 小游戏项目架构](<./Unity 小游戏项目架构.md>)。

## 结论（影响行动的部分）

1. **System.Net 全系在 WebGL 不可用**（Sockets/Http/WebSockets 编译报错），HTTP 走 UnityWebRequest、TCP 走 WebSocket 或微信 TCPSocket。限制原理与基本映射主存在 WebGL坑 §3.5，本条目讲**怎么配、怎么用、怎么排查**。
2. **上线必须配安全域名 + HTTPS/WSS**：MP 后台「开发-开发管理-开发设置-服务器域名」，HTTP 设 request/download 合法域名、WebSocket 设 socket 合法域名。开发阶段用调试模式可免域名免证书。
3. **「开发者工具正常真机异常」「开调试正常关调试异常」几乎都是安全域名/SSL 证书问题**——工具默认不校验、真机默认校验、调试模式不校验。这是最高频的网络坑，先按 §三排查。
4. **实时通信按需选**：TCP 用 `WX.CreateTCPSocket`（需微信基础库 ≥3.1.1）或 WebSocket；UDP 用 `WX.CreateUDPSocket`。休闲单机小游戏通常只需 HTTP（远程 AB/CDN/排行榜），TCP/UDP/WebSocket 是多人/实时通信才用。

## 一、HTTP 通信（UnityWebRequest）

来源：Design/UsingNetworking.md「HTTP 通信」节（镜像核实 2026-11-13）。官方规定。

- WebGL 用 `UnityWebRequest`（底层浏览器 Fetch API，自动走 CORS）；小游戏环境下被 unity-webgl-transform 工具自动替换成 `wx.request` / `tt.request`（详见 WebGL坑 §3.5/§5）。
- **必须协程等待，禁止阻塞**：

```csharp
IEnumerator Get()
{
    UnityWebRequest req = UnityWebRequest.Get("https://mysite.com");
    yield return req.SendWebRequest();          // 交回控制权给浏览器
    if (req.isHttpError || req.isNetworkError) Debug.Log(req.error);
    else Debug.Log(req.downloadHandler.text);
}
```

- **反例（会卡死游戏）**：`while(!req.isDone) {}`。WebGL 单线程 + JS 网络 API 异步，不交回控制权下载永远不完成。POST 用 `WWWForm` + `UnityWebRequest.Post(url, form)`，同样协程等待。

## 二、安全域名配置（上线硬约束）

来源：Design/UsingNetworking.md「注意事项/安全域名」节（镜像核实 2026-11-13）；配置入口 [微信网络说明](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/network.html)（原页待浏览器复核）。官方规定。

| 项 | 要求 |
|----|------|
| 配置入口 | mp.weixin.qq.com 后台 → **开发 → 开发管理 → 开发设置 → 服务器域名** |
| HTTP 请求 | 设到 **request 合法域名**；下载设到 **downloadFile 合法域名** |
| WebSocket | 设到 **socket 合法域名** |
| 协议 | 上线必须 **HTTPS / WSS**（带 SSL 证书） |

- 真机预览默认校验安全域名；手机端小游戏右上角菜单「开启调试」可临时不校验。
- 微信开发者工具默认不校验安全域名/SSL；「详情 → 本地设置 → 关闭『不检验合法域名、HTTPS 证书』」可强制校验，用于上线前自查。

## 三、真机网络异常排查（最高频坑）

来源：Design/UsingNetworking.md「注意事项」节（镜像核实 2026-11-13）。官方规定 + 排查分支。

**典型症状**：「开发者工具正常，真机访问异常」或「打开调试正常，关闭调试异常」。

**根因**：安全域名与 SSL 证书的校验差异——

| 环境 | 安全域名 | SSL 证书 |
|------|----------|----------|
| 微信开发者工具 | 默认不校验 | 默认不校验 |
| 真机（关调试） | **校验** | **校验**（HTTPS/WSS 必须有证书，无法关闭） |
| 真机（开调试） | 不校验 | 可用 HTTP/WS 无证书 |

**排查分支**：

```
真机网络失败 / 工具正常真机异常？
├─ 关调试才失败、开调试正常 → 安全域名未配 或 SSL 证书问题
│   ├─ 查 MP 后台服务器域名是否登记了该 URL（request/download/socket 分类对不对）
│   └─ 查 SSL 证书是否过期（在线工具 https://myssl.com/ssl.html 检测）
├─ 开发阶段无正式域名/无证书 → 用开发者工具或真机调试模式 + HTTP/WS 先跑通
│   └─ 上线前必须换 HTTPS/WSS + 登记安全域名（玩家不可能开调试）
└─ 工具也失败 → 不是域名问题，查 URL/服务端/协程阻塞（§一）
```

**开发阶段无 SSL/无正式域名能否跑**：能。开发者工具或调试模式真机无需登记安全域名，可用 HTTP/WS。**正式上线必须 HTTPS/WSS + 安全域名**。

## 四、TCP 通信（微信 TCPSocket，多人/实时按需）

来源：Design/UsingNetworking.md「TCP 网络通信」节（镜像核实 2026-11-13）；[TCPSocket.onMessage](https://developers.weixin.qq.com/minigame/dev/api/network/tcp/TCPSocket.onMessage.html)（原页待浏览器复核）。官方规定。

- 微信基础库 **≥3.1.1** 提供 TCPSocket；否则用 WebSocket 替代（§五）。
- 最小流程：`WX.InitSDK` → `WX.CreateTCPSocket()` → 注册 `OnConnect/OnError/OnMessage` → `Connect(new TCPSocketConnectOption{ address, port })` → 连接成功后 `Write(...)`。

```csharp
WXTCPSocket tcp = WX.CreateTCPSocket();
tcp.OnConnect(res => tcp.Write("TCP Write Test"));
tcp.OnError(res => Debug.Log("tcp 失败 " + res.errMsg));
tcp.OnMessage(res => Debug.Log(Encoding.UTF8.GetString(res.message)), true);
tcp.Connect(new TCPSocketConnectOption { address = "www.example.com", port = 8848 });
```

- **OnMessage 坑（表现与文档不一致）**：签名 `OnMessage(Action<TCPSocketOnMessageListenerResult> listener, bool needInfo = false)`。
  - `needInfo=false` 时 `localInfo`/`remoteInfo` 返回 null；`true` 会**降低性能**，按需使用。
  - 多次 `OnMessage` 时 needInfo **以第一个为准**；`OffMessage()` 移除所有回调后再次 OnMessage 才能重设 needInfo。

## 五、WebSocket（TCP 的通用替代）

来源：Design/UsingNetworking.md「WebSocket」节（镜像核实 2026-11-13）。官方规定 + 外部案例。

- **客户端**：第三方插件较多，文档以 [UnityWebSocket](https://github.com/psygames/UnityWebSocket)（psygames）为例：`new WebSocket(address)` → 注册 `OnOpen/OnClose/OnMessage/OnError` → `ConnectAsync()` → `SendAsync(bytes)`（建议 byte[]）→ `CloseAsync()`。
  - **旧版需改 WebSocket.jslib 两处**（新版已修复无需改）：① `instance.ws.onmessage` 把 `else if (ev.data instanceof Blob)` 分支挪到最后；② `WebSocketSend` 中 `HEAPU8` 改为 `buffer`。
- **服务端**：若原服务是 TCP 接入，需 **WSS↔TCP 代理层**——Nginx / [websockify-js](https://github.com/novnc/websockify-js) / [websockify](https://github.com/novnc/websockify) 反向代理（推荐），或改造 TCP 服务兼容 wss。
- **粘包坑**：WebSocket 数据包的「粘包」问题需**游戏服务器自行处理**（框架不代劳）。

## 六、UDP 通信（微信 UDPSocket，按需）

来源：Design/UsingNetworking.md「UDP 网络通信」节（镜像核实 2026-11-13）；[UDPSocket.onMessage](https://developers.weixin.qq.com/minigame/dev/api/network/udp/UDPSocket.onMessage.html)（原页待浏览器复核）。官方规定。

- 微信基础库提供 UDPSocket。最小流程：`WX.InitSDK` → `WX.CreateUDPSocket()` → 注册 `OnMessage` → `Bind()` 绑定端口 → `Send(new UDPSocketSendOption{ address, port, message })`。
- `OnMessage` 的 needInfo 行为同 TCP（§四）：false 时 localInfo/remoteInfo 为 null，true 降性能，多次以第一个为准。
